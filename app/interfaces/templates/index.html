Proyectos

ReHuse Server
Backend para gestión de rutinas de fisioterapia

ReHuse Server es el backend del proyecto ReHuse, una plataforma creada para ayudar a reducir las listas de espera en fisioterapia del Hospital Son Espases, permitiendo a los profesionales enviar rutinas personalizadas a distancia.

Stack: Python, FastAPI, MySQL, Docker

- Gestión de pacientes, ejercicios y rutinas de rehabilitación - Creación y reutilización de plantillas de rutinas personalizadas - Asociación de imágenes a ejercicios - Organización de contenidos mediante etiquetas categorizadas - Validación y procesamiento de datos clínicos y funcionales

- API REST estructurada para consumo por frontend - Backend orientado a escalabilidad y reutilización de datos - Separación clara de responsabilidades y lógica de negocio

Grumete
Módulo de Servicios Remotos

Grumete es una aplicación de escritorio para el monitoreo técnico de dispositivos físicos y servicios remotos, desarrollada con arquitectura modular.

Stack: Python, FastAPI, MySQL, Docker, PySide6

- Monitoreo en tiempo real del estado de conexión de dispositivos - Registro de eventos críticos (desconexiones, reconexiones, latencia) - Gestión y monitoreo de APIs REST mediante tareas automatizadas - Análisis de métricas de rendimiento con alertas visuales
